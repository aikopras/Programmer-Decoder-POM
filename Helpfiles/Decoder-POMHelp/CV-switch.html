CV values used by the switch, relays-4 and servo decoders

In addition to the CVs common to all decoders, these decoders use the CVs below.

Decoder types

DecType (CV27)Decoder Type (Control tab)Decoder
16switchSwitch decoder
17switch plusSwitch decoder with emergency board
20servo-2Servo decoder for 2 servos
21servo-3Servo decoder for 3 servos
22servo-6Servo decoder for 6 servos
32relays-4Relays decoder for 4 relays

CVs

CVNameAccessRangeDescription
3..6T_on_F1 .. T_on_F4R/W0..255Switch and relays-4 decoders: activation time of output 1..4, in 20 ms steps. 0 = continuous activation
33SendFBR/W0..1If 1: the decoder sends switch feedback via the RS-Bus. Should be 0 if the decoder only sends PoM feedback (RS-Bus address 128)
34AlwaysActR/W0..1If 1: the decoder activates the coil, relays or servo for each DCC command, also if it is already in the requested position. Needed by train control software that expects a feedback message after each switch command
35SwitchCountR/W0..255Number of connected switches or servos. 0 or 255: the maximum number supported by the hardware. New decoders only
36SwitchTypeR/W0..20 = normal, 1 = Weinert DKW with Spurkranzlenkung, 2 = double crossover. New decoders only

The servo specific settings (such as end positions and speed) are normally set with a handheld. See the documentation of the servo decoder on GitHub.
