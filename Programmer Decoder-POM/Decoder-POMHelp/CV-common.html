CV values common to all decoders

The CVs below are used by all decoders. Old decoders use the OPENDECODER22 software; new decoders use the AP_DCC_Decoder_Core library. CVs marked New decoders only are not supported by old decoders: old decoders return 0 for these CVs and ignore new values.

Default values can be restored with the DEFAULTS buttons, or for all CVs at once by writing 13 to CV8. A complete overview of the CVs of the new decoders, including default values and the CVs of decoders not described in this help, can be found on GitHub.

CVNameAccessRangeDescription
1myAddrLR/WDecoder address, low order bits. See Understanding Decoder Addresses
7versionRSoftware version
8VIDR/W13Vendor ID (13 = 0x0D: DIY decoder). Writing 13 resets all CVs to their default values
9myAddrHR/WDecoder address, high order bits. 128 (0x80) means: address not set
10myRSAddrR/W1..128RS-Bus address. 0 means: address not set
19CmdStationR/W0..2Command station: 0 = standard (such as Roco), 1 = Lenz, 2 = OpenDCC Z1 (new decoders only)
20RSRetryR/W0..2Number of additional transmissions of each RS-Bus feedback message (also called RSFEC)
21SkipUnEvenR/W0..1If 1: only decoder addresses 2, 4, 6 ... are used
22RSParityR/W0..2Reaction to a RS-Bus parity error: 0 = no reaction, 1 = retransmit if data was just transmitted, 2 = always retransmit. New decoders only
23SearchR/W0..1If 1: the decoder LED blinks. Not stored; 0 after a restart
24RSPulsCountR/W0..2Reaction to a RS-Bus pulse count error: same values as CV22. New decoders only
25RestartWWriting a value other than 0 restarts the decoder, so that new CV values take effect
26DccQualityR0..255Number of DCC checksum errors since the last restart
27DecTypeRDecoder type. See the pages of the individual decoders
28RailComR0RailCom (BiDi) is not supported
29ConfigRAccessory decoder configuration (similar to CV29 of the NMRA)
30VID_2R13Second vendor ID, to recognise decoders by Aiko Pras
31ParityErrorsR0..255Number of RS-Bus parity errors since the last restart. New decoders only
32PulseErrorsR0..255Number of RS-Bus pulse count errors since the last restart. New decoders only
