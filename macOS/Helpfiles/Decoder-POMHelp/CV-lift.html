CV values used by the lift decoder

In addition to the CVs common to all decoders, the lift decoder uses the CVs below. These CVs can be modified on the Lift tab, which is only shown if the selected decoder is a lift decoder. After SELECT, these CVs are read together with the common CVs.

Decoder type

DecType (CV27)Decoder Type (Control tab)Decoder
24liftLift decoder

CVs

CVNameAccessRangeDefaultDescription
33StartHomingR/W0..11If 1: the decoder performs a homing cycle at start-up, so the lift moves to a defined position. Takes effect after a restart of the decoder
34IR_DetectR/W0..11If 1: the IR-sensors are checked before the lift starts moving. If a train blocks an IR-beam, the lift will not move. 0 may be needed for testing, or if no IR-Sensor board is connected
35LCD_DisplayR/W0..10If 1: the LCD display is used. Since writing to the LCD takes quite some time, it may interfere with RS-Bus feedback and other time critical functions. Intended for testing
36Serial_LineR/W0..20Serial monitor interface. 0 (Off): switched off. 1 (On): input from the serial line is copied to the GRBL processor, and the lift position is shown. 2 (Details): in addition, all output of the GRBL processor is shown. Needed to make GRBL configuration changes. Switching on (from 0 to 1 or 2) takes effect after a restart of the decoder

A restart can be done with the RESTART button in the main window. The documentation of the lift decoder can be found on GitHub.
