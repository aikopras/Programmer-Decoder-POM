CV values used by the servo decoders

In addition to the CVs common to all decoders, the servo decoders use the CVs below. They can be modified on the tabs Servo, Servo positions and Servo CVs, which are only shown if the selected decoder is a servo decoder. After SELECT, these CVs are read for the first servo; after choosing another servo, the CVs of that servo are read.

Except for the live setting (see below), new values are used by the decoder after a restart. A restart can be done with the RESTART button in the main window.

Servo positions tab (live setting)

On this tab the end positions (Min and Max) and the Speed of one servo can be set, while the servo shows every change directly. This requires decoder software version 24 or higher.

  • Choose the servo, and press START. The servo moves once away and back, to show which servo is selected. As long as the live setting is active, the decoder ignores switch commands, and another tab, decoder or servo can not be selected.
  • Choose Min, Max or Speed. With Min or Max the servo moves to that side and stays there. With Speed the servo moves continuously back and forth.
  • Change the value with the slider, the field or the stepper (1 µs per step). Min and Max range from 544 to 2400 µs, Speed from 1 to 50. Changing a value also selects Min, Max or Speed. Every change is written into the decoder directly.
  • MIDDLE sets Min or Max to 1500 µs. DEFAULTS sets Min to 1300 µs, Max to 1700 µs and Speed to 6.
  • DONE ends the live setting. CANCEL first restores the values read before START, and then ends the live setting. The servo returns to the side where it started.

If + and - are swapped after setting, change InvertServoDir on the Servo CVs tab. When the program is closed during a live setting, the live setting is ended first.

The live setting uses two command CVs that only exist in RAM: CV62 (0 = idle, 1 = Min, 2 = Max, 3 = Speed) and CV63 (0 = ready, 1..CV64 = servo).

Servo CVs

On the servo-3 board, Generic and Uhlenbrock 81420 / Weinert servos do not always work reliably with PowerWhenIdle = No; use Yes for these servos.

The DEFAULTS button of the Servo CVs tab sets ServoType Generic, with PowerWhenIdle Yes on the servo-3 board and No on the servo-2 and servo-6 boards. Changing the ServoType does not change PowerWhenIdle; set it according to the table above.
